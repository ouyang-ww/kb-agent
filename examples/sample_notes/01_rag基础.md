# RAG 基础

## 什么是 RAG
RAG（Retrieval-Augmented Generation，检索增强生成）是一种将信息检索与大语言模型生成相结合的架构。它先从一个知识库中检索出与问题相关的文档片段，再把这些片段作为上下文提供给 LLM 生成答案。

## RAG 的组成
1. 索引阶段：文档加载 → 清洗 → 切块 → 向量化 → 写入向量库
2. 检索阶段：问题向量化 → 相似度检索 top-k
3. 生成阶段：检索片段 + 问题组装提示词 → LLM 生成带引用的答案

## RAG 的优缺点
优点：答案可溯源、可更新知识而不重训模型、降低幻觉。
缺点：检索质量决定上限，需要维护索引，多一跳延迟。
